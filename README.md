# Fabricae PINE

Auto-generated website for Fabricae PINE — Clothing manufacturer, vanraj mandal, Yadav Vyapar Bhavan, bus stop, Shop no 14 and 15, Chhatrapati Shivaji Maharaj Rd, near Mamledar Kacheri Road, Shukrawar Peth, Pune, Maharashtra 411002.

## Tech Stack

- **database**: PostgreSQL
- **frontend**: React 19 + TypeScript on Vite, react-router-dom, Tailwind CSS
- **backend**: Spring Boot 3 (Java 17) + Spring Data JPA

## Features

- High-Quality, Filterable Product Catalog
- Mobile-Responsive Design
- B2B Client Registration and Gated Content (e.g., wholesale pricing)
- Bulk Order Inquiry Form with MOQ fields
- SEO-Optimized Content Structure
- Embedded Google Map and Click-to-Call Functionality

## Running Locally

```bash
docker-compose up --build
```

The app will be available at http://localhost:8080

## Development

**Backend:**
```bash
cd backend && mvn spring-boot:run
```

**Frontend:**
```bash
cd frontend && npm install && npm run dev
```
